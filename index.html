Custom TURN / Relay Server (Optional)
For Strict Firewalls / Symmetric NAT
By default, Setu uses direct peer-to-peer WebRTC via public STUN. If you or your peer are behind strict corporate firewalls, mobile CGNAT, or Symmetric NATs where direct connections fail, specify your own TURN relay server. Credentials are saved only in your local browser.
Custom API Signaling Gateway (Optional)
Serverless / Self-Hosted
Register meetings on your own single HTTPS API endpoint (e.g. Google Apps Script, Cloudflare Worker, FastAPI, Node.js, PHP). End-to-End Encrypted (AES-GCM-256) so your endpoint only stores opaque ciphertext. Your host secret key is strictly private and never included in invite links.
