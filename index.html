Open-Source WebRTC Platform
“Setu brings video conferencing, screen sharing, remote assistance, and collaboration together in an open-source platform designed around software freedom and deployment flexibility.”

Mainstream conferencing tools lock organizations into closed cloud silos, recurring seat licenses, and opaque data pipelines. Lightweight open-source tools frequently stop at video or text chat. Setu bridges the gap by combining end-to-end encrypted 1-to-1 WebRTC calling, low-latency screen sharing, collaborative whiteboarding, chunked file transfer, and host-consented remote desktop control into a single, zero-install web client.

Core Capabilities & Features

Every tool required for direct communication and hands-on remote collaboration, engineered directly into your browser.

Video & Audio Calling

Direct WebRTC peer-to-peer audio and video encrypted with DTLS and SRTP. Real-time media travels directly between browsers with minimal latency and zero central media intermediaries.

High-Definition Screen Sharing

Stream full desktops, individual application windows, or browser tabs at native resolution. Features dynamic aspect-ratio adaptation, presenter mode, and system audio capture.

Consensual Remote Assistance

Provide live technical support and interactive collaboration. Presenters authorize remote mouse clicks, scrolling, and keyboard input via the native Setu Companion daemon over an authenticated local loopback link.

Encrypted Messaging & File Transfer

Communicate over real-time WebRTC DataChannels with client-side AES-GCM (256-bit) encryption. Stream large files peer-to-peer using chunked transfer and SHA-256 integrity verification without file size caps or cloud ingestion.

Interactive Whiteboard & Notes

Sketch ideas simultaneously on a synchronized low-latency HTML5 canvas with pens, shapes, text, and eraser tools. Keep shared session notes saved directly into your browser's persistent storage.

Software Freedom & Transparency

Licensed under the permissive Apache License 2.0. Inspect every line of client code, modify components freely, and host statically on GitHub Pages, Cloudflare Pages, or private air-gapped intranets.

Local-First Privacy Architecture

No user tracking cookies, centralized telemetry databases, or account registration. Saved room IDs, contact shortcuts, and preferences remain isolated inside your browser's local IndexedDB.

How Setu Works

Four streamlined steps from room creation to an encrypted direct peer session.

1

Open or Host

Launch an instant disposable room or start your permanent reusable room code with one click. No registration, email verification, or passwords needed.

2

Share Room Key

Send an 8-character code, direct invitation URL, or scan the on-screen QR code from a mobile device or secondary computer.

3

Direct P2P Handshake

Both browsers exchange session descriptors over ephemeral serverless channels, establishing direct DTLS/SRTP encrypted WebRTC media streams.

4

Collaborate & Control

Communicate via video and chat, share screens, sketch on canvas, or enable consensual remote assistance through Setu Companion.

Frequently Asked Questions & Architecture

What is Setu P2P?

Setu P2P is an open-source, strictly serverless WebRTC video conferencing application running entirely inside your web browser without project-operated signaling servers, user accounts, or cloud databases.

Does Setu support remote desktop control?

Yes. Setu includes consensual remote desktop control during screen sharing sessions. Presenters run the lightweight native Setu Companion daemon on their machine over an authenticated loopback WebSocket (ws://127.0.0.1:49152) requiring session passkeys, relative coordinate scaling, and multi-step host approval.

Is Setu P2P private and encrypted?

Yes. Audio, video, and screen sharing streams are encrypted using WebRTC SRTP (AES-CM), and data channels use DTLS 1.2/1.3. Local chat messages can be encrypted with client-side AES-GCM (256-bit) using WebCrypto PBKDF2.

How does Setu establish calls without central servers?

Setu supports manual non-trickle ICE exchange via copy-paste codes, camera-scannable QR codes, and human-friendly 8-character room codes (SETU-XXXX-XXXX) with automated collision-avoidance probing via ephemeral serverless gateways.

Are calls or recordings stored in the cloud?

No. Recording requires mutual consent from both participants. Media is mixed locally inside the browser using MediaRecorder and Web Audio API, saving the final video file directly to the user's local disk.

Is Setu free and open source?

Yes. Setu P2P is 100% free and open source licensed under the Apache License 2.0. You can self-host it statically on GitHub Pages, Cloudflare Pages, or any web server.
